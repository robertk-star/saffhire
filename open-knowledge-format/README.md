# SaffHire.com Open Knowledge Format (OKF)

This folder is a structured knowledge base for the SaffHire website and related internal app links. It is meant to help future AI chats, developers, writers, and builders understand the business, website, routes, services, audiences, brand voice, compliance boundaries, conversion goals, and technical context without rereading the full codebase.

Generated from the uploaded current GitHub files: `saffhire-main (1).zip`.

Last reviewed: 2026-07-29.

## How to use this folder

Use this folder as the first place to look before making website, content, SEO, admin, or app-link changes.

1. `01-business-overview.md`
2. `02-brand-and-voice.md`
3. `03-services.md`

## Important rule

This OKF folder is documentation only. It should not change how the website runs unless future code intentionally reads from it.
