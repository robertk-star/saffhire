# Conversion Goals

## Primary public conversion goals

1. Get Quote / Contact request
2. Create Account / Start account setup
3. Client Login
4. Phone call
5. Guide/resource engagement

## Main CTA routes and links

- Contact page: `/contact`
- Homepage contact anchor: `/#contact`
- Account setup: `https://intake.saffhire.com/`
- Client login: `https://saffhire.instascreen.net/sso/login.taz`
- Blog: `/blog`
- Background Screening Guides: `/background-screening-guides`

## Tracking already reflected in code

The codebase includes conversion-oriented attributes/events in areas such as footer links, contact form submission, account setup links, login links, social clicks, and guide hub clicks.

## Funnel guidance

Public visitors should be able to quickly understand:

- What SaffHire does
- Who SaffHire helps
- What services are available
- Why SaffHire is trustworthy
- How to request a quote or create an account

## Internal tools conversion goal

The `/apps` page is not a public marketing funnel. It is a noindex/nofollow internal app link hub for apps being built.
